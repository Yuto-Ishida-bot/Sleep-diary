# 睡眠・活動ダイアリー

スマートウォッチの睡眠計測結果と、疲労度・体調・睡眠薬・カフェイン/アルコールを記録し、それらの相関を分析するAndroid向けWebアプリ(PWA)です。すべてのデータは端末内のブラウザにのみ保存され、外部サーバーには一切送信されません。

## 記録できる項目

- **就床・起床**: 就寝時刻と起床時刻から「床上時間」を自動計算
- **睡眠ステージ**: 深い睡眠 / 浅い睡眠 / レム睡眠を時間・分で入力、目が覚めた回数(中途覚醒)
  - 3つのステージの合計から「**実睡眠時間**(中途覚醒を除いた正味の睡眠)」を自動計算
  - 実睡眠時間 ÷ 床上時間 で「**睡眠効率**」も自動計算
- **疲労度・体調**: それぞれ1〜5段階。**どちらも 1 が良い状態**に揃えてあります
  - 疲労度: 1 = 疲労なし 〜 5 = 非常に疲れている
  - 体調: 1 = とても良い 〜 5 = とても悪い
- **睡眠薬**: 内服の有無と薬剤名(候補付き自由入力)
- **☆**: タップで ☆ ⇄ ★ を切り替える記録項目
- **カフェイン・アルコール**: それぞれ杯数
- **メモ**: 自由記述

## スマートウォッチの記録の入力方法

スマートウォッチのアプリで睡眠の詳細画面を開き、そこに表示されている値をそのまま入力します。たとえば「深い睡眠 1時間37分 / 浅い睡眠 4時間9分 / レム睡眠 42分 / 目が覚めた回数 3回」と表示されていれば、その数字を各欄に入れるだけです。実睡眠時間と睡眠効率は入力に応じて自動で計算・表示されます。

多くのスマートウォッチアプリで表示される「夜間の睡眠」の合計時間は、すでに中途覚醒の時間を除いた値になっており、3つのステージの合計と一致します。このアプリでもステージ合計を実睡眠時間として扱っているため、同じ数字になるはずです。

## 分析機能

- **概要**: 記録日数、平均実睡眠時間、平均深い睡眠、平均レム睡眠、平均疲労度、平均体調、平均中途覚醒回数
- **時系列グラフ**: 実睡眠時間と疲労度の推移
- **睡眠ステージの内訳**: 日ごとの深い/浅い/レム睡眠を積み上げ棒グラフで表示
- **相関分析**: 相関係数 r と散布図・回帰直線、さらに向きを日本語で説明。以下の組み合わせを切り替えて確認できます
  - 実睡眠時間 / 深い睡眠 / 浅い睡眠 / レム睡眠 / 中途覚醒回数 / 睡眠効率 × 疲労度
  - 深い睡眠 × 体調
  - 睡眠薬 × 実睡眠時間、睡眠薬 × 深い睡眠
  - カフェイン・アルコール × 実睡眠時間、アルコール × 深い睡眠
  - 前日のカフェイン / アルコール × 翌日の疲労度
  - ☆ × 疲労度、前日☆ × 翌日疲労度、☆ × 深い睡眠

外部ライブラリには依存せず、グラフはすべて自前のSVG描画で実装しているため、完全オフラインで動作します。

## Androidで使うには(ホスティングが必要です)

このアプリは静的なWebアプリ(PWA)です。ファイルをそのままAndroid端末で開くだけでは、ホーム画面への追加やオフラインキャッシュが正しく機能しないため、どこかにファイル一式をホスティングする必要があります。

### 方法A: GitHub Pages(恒久的・無料・GitHubアカウントが必要)

1. GitHubで新しいリポジトリを作成する(GitHub Pagesを無料で使うには **Public** である必要があります)
2. このフォルダの中身(index.html, manifest.json, css/, js/, icons/, service-worker.js)を、リポジトリの**ルート直下**にすべてアップロード
3. リポジトリの Settings → Pages を開き、Source で「Deploy from a branch」、Branch で「main」と「/ (root)」を選んで Save
4. 1〜2分待ってから同じ画面を再読み込みすると「Your site is live at https://ユーザー名.github.io/リポジトリ名/」と表示されます
5. そのURLをAndroidのChromeで開く

### 方法B: Netlify Drop(お試し用・アカウント不要)

1. PCのブラウザで https://app.netlify.com/drop を開く
2. このフォルダをまるごとドラッグ&ドロップ
3. 発行されたURLをAndroidのChromeで開く
4. ※サインアップしないと24時間で公開が失効するため、継続して使う場合は無料アカウントで発行後にサイトを「claim」してください

## ホーム画面への追加

上記いずれかの方法でURLを発行した後、Android版Chromeでそのページを開くと、画面上部に「ホーム画面に追加してアプリのように使えます」というバナーが表示されます。「追加」をタップすると、ホーム画面にアイコンが追加され、アプリのように起動できます(オフラインでも利用可能)。

## データのバックアップについて重要

記録データは端末のブラウザ内(localStorage)にのみ保存されます。機種変更やブラウザのデータ消去、アプリのアンインストールでデータが失われる可能性があるため、「履歴」タブの **エクスポート** ボタンで定期的にJSONファイルとして保存しておくことを強くおすすめします。復元は同タブの **インポート** ボタンから、エクスポートしたJSONファイルを選択してください(同じ日付の記録は上書き、新しい日付は追加されます)。

旧バージョン(体調が 1=悪い 〜 5=良い だった頃)のデータは、アプリを開いた時点で自動的に新しい向き(1=良い)へ変換されます。旧バージョンのバックアップJSONをインポートした場合も同様に変換されます。

## 分析結果の見方

相関係数 r は -1〜1 の値で、絶対値が0.5以上で「強い相関」、0.3〜0.5で「中程度の相関」、それ未満で「弱い相関」と表示されます。疲労度・体調はどちらも数値が小さいほど良い状態なので、たとえば「深い睡眠 × 疲労度」で r がマイナスであれば、深い睡眠が長い日ほど疲労が軽い、という関係を意味します(画面下部に日本語の説明も表示されます)。

ただし記録日数が少ないうちは数値が不安定になりやすいので、ある程度(2〜3週間分など)データが貯まってから傾向を見ることをおすすめします。また、相関は因果関係を証明するものではありません。生活の変化や体調不良など、記録していない要因が両方に影響している可能性も踏まえて解釈してください。健康上の心配がある場合は、記録を持参して医療機関に相談することをおすすめします。
