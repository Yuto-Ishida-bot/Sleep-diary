# 睡眠・活動ダイアリー

睡眠・日中の活動・疲労度・体調・カフェイン/アルコール摂取を記録し、それらの相関を分析するAndroid向けWebアプリ(PWA)です。すべてのデータは端末内のブラウザにのみ保存され、外部サーバーには一切送信されません。

## 主な機能

- **記録**: 就寝/起床時刻(睡眠時間を自動計算)、疲労度・体調(1〜5)、日中の活動内容と時間(複数登録可)、カフェイン・アルコール摂取量、メモ
- **履歴**: 過去の記録一覧・編集・削除、JSON形式でのエクスポート/インポート(バックアップ)
- **分析**:
  - 睡眠時間と疲労度の時系列グラフ
  - 6種類の相関分析(相関係数 r と散布図・回帰直線を表示)
    - 睡眠時間 × 疲労度
    - 日中の活動時間 × 疲労度
    - カフェイン量 × 睡眠時間
    - アルコール量 × 睡眠時間
    - 前日のカフェイン量 × 翌日の疲労度
    - 前日のアルコール量 × 翌日の疲労度

外部ライブラリ(Chart.js等)には依存せず、グラフはすべて自前のSVG描画で実装しているため、完全オフラインで動作します。

## Androidで使うには(ホスティングが必要です)

このアプリは静的なWebアプリ(PWA)です。ファイルをそのままAndroid端末で開くだけでは、ホーム画面への追加やオフラインキャッシュが正しく機能しないため、どこかにファイル一式をホスティングする必要があります。以下のいずれかが簡単です。

### 方法A: GitHub Pages(恒久的・無料・GitHubアカウントが必要)

1. GitHubで新しいリポジトリを作成
2. このフォルダの中身(index.html, manifest.json, css/, js/, icons/, service-worker.js)をすべてアップロード
3. リポジトリの Settings → Pages で公開を有効化
4. 発行されたURL(例: `https://ユーザー名.github.io/リポジトリ名/`)をAndroidのChromeで開く

### 方法B: Netlify Drop(お試し用・アカウント不要)

1. PCのブラウザで https://app.netlify.com/drop を開く
2. このフォルダをまるごとドラッグ&ドロップ
3. 発行されたURLをAndroidのChromeで開く
4. ※サインアップしないと24時間で公開が失効するため、継続して使う場合は無料アカウントで発行後にサイトを「claim」してください

## ホーム画面への追加

上記いずれかの方法でURLを発行した後、Android版Chromeでそのページを開くと、画面下部に「ホーム画面に追加してアプリのように使えます」というバナーが表示されます。「追加」をタップすると、ホーム画面にアイコンが追加され、アプリのように起動できます(オフラインでも利用可能)。

## データのバックアップについて重要

記録データは端末のブラウザ内(localStorage)にのみ保存されます。機種変更やブラウザのデータ消去、アプリのアンインストールでデータが失われる可能性があるため、「履歴」タブの **エクスポート** ボタンで定期的にJSONファイルとして保存しておくことを強くおすすめします。データを復元する際は同タブの **インポート** ボタンから、エクスポートしたJSONファイルを選択してください(同じ日付の記録は上書き、新しい日付は追加されます)。

## 分析結果の見方

相関係数 r は -1〜1 の値で、絶対値が0.5以上で「強い相関」、0.3〜0.5で「中程度の相関」、それ未満で「弱い相関」と表示されます。ただし記録日数が少ないうちは数値が不安定になりやすいので、ある程度(2〜3週間分など)データが貯まってから傾向を見ることをおすすめします。また相関は因果関係を証明するものではない点にもご留意ください。
